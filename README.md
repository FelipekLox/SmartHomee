# 🏠 Умный дом 2.0 (SmartHome)

Консольное приложение на языке **C#**, моделирующее систему управления устройствами умного дома. Проект разработан для демонстрации ключевых принципов объектно-ориентированного программирования (наследование, инкапсуляция, полиморфизм, абстракция, перегрузка методов) и командной работы по методологии **Git-Flow**.

---

## ✨ Возможности программы

* **Единое управление устройствами:** все приборы хранятся в общем массиве `SmartDevice[]` и управляются полиморфно без проверок конкретных типов (`switch` / `is`).
* **Интерактивное консольное меню:**
  1. Просмотр актуального статуса и параметров всех устройств.
  2. Массовое включение всех устройств.
  3. Массовое выключение всех устройств.
  4. Точечное включение устройства по имени (без учёта регистра).
  5. Точечное выключение устройства по имени.
  6. Статистика активных и выключенных приборов.
  7. Расчёт суммарного энергопотребления (в ваттах) включённых устройств.
  8. Активация сценария **«Вечер»** (одновременный запуск освещения, умной колонки и термостата).
* **Перегрузка методов:** гибкая настройка яркости умного света (`SetBrightness(int)` для точного процента и `SetBrightness(string)` для готовых пресетов: *«ночь»*, *«вечер»*, *«максимум»*).

## 🧱 Архитектура и устройства

Все модели вынесены в пространство имён `SmartHome.Models` (папка `Models/`) с соблюдением инкапсуляции (`private set`):

* **`IEnergyConsumer`** — интерфейс для расчёта текущего энергопотребления (`GetPowerConsumption()`).
* **`SmartDevice`** — базовый абстрактный класс для всех приборов с абстрактным методом `GetStatus()`.
* **Базовые устройства:**
  * `SmartLight` — умное освещение (регулировка яркости).
  * `Thermostat` — термостат (поддержание целевой температуры).
  * `SmartSpeaker` — умная колонка (управление громкостью).
* **Расширенные устройства:**
  * `SecurityCamera` — камера видеонаблюдения (управление статусом записи).
  * `RobotVacuum` — робот-пылесос (контроль уровня заряда батареи).
  * `SmartKettle` — умный чайник (`sealed`-класс с заданием температуры нагрева воды).


## 🚀 Как запустить

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте решение `SmartHome.slnx` в **Visual Studio** и нажмите **Пуск (`F5`)**, либо запустите через терминал:
   ```bash
   dotnet run
   ```

## 🌿 Ветвление (Git-Flow)

Разработка велась с соблюдением модели **Git-Flow**:
* `main` — стабильные релизы (актуальный тег **`v1.0`**).
* `develop` — основная ветка интеграции задач.
* `feature/*` — изолированные ветки под каждую функциональность (`base-devices`, `new-devices`, `console-menu`, `method-overload`), влитые через `--no-ff`.
* `release/1.0` — ветка подготовки первого релиза.
